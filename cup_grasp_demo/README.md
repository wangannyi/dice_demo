# 抓杯摇骰 Pipeline

当前主流程为绿色开口杯：HOME → CAPTURE → PLAN → APPROACH → GRIP → LIFT → SHAKE → LOWER → OPEN → RETURN_HOME。顶层 run.sh 使用 configs/green_cup.json；银杯侧抓保留为独立历史策略，不是当前默认流程。
